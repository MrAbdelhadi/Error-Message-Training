# 🪟 Error Messages Education | محاكاة رسائل الخطأ

**EN:** A Windows error/warning dialog simulator for training and education.  
**AR:** برنامج لمحاكاة رسائل الخطأ في ويندوز لأغراض تعليمية وتدريبية.

---

## 🇬🇧 English Description

**Error Messages Education** is a lightweight educational tool that simulates native Windows error messages.  
It is designed for students and trainees to visually recognize how real system dialogs look, so they become familiar with them before encountering them in real situations.  
The app does not modify the system — it only displays safe UI simulations.

### ✅ Features
- Realistic Windows-style dialogs (Error / Warning / Information).
- Built-in presets for common errors (File not found, Access denied, etc.).
- Custom dialog builder (title, text, icon, buttons).
- Safe playground for IT students and beginners.
- Runs on **.NET Framework 4.7.2** (Windows 7 supported).

### 📌 Requirements
- Windows 7 SP1 or newer
- .NET Framework 4.7.2
- Visual Studio (optional if building from source)
